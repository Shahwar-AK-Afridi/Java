
# Words in Files

## Problem Statement

Build a Java program that determines which files contain
specific words using a HashMap.

## Requirements

1. Read multiple text files using DirectoryResource.
2. Store each unique word as a HashMap key.
3. Map each word to an ArrayList of filenames.
4. Prevent duplicate filenames for the same word.
5. Find the maximum number of files containing any word.
6. Find words appearing in exactly N files.
7. Print the filenames containing a specified word.

## Java Concepts Practiced

- HashMap
- ArrayList
- FileResource and DirectoryResource
- Loops and conditionals
- Methods and encapsulation
