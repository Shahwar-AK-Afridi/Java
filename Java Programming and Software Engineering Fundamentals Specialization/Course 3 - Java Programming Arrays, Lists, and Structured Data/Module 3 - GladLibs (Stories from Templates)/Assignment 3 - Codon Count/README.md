# Codon Count

## Problem Summary
Create a Java program to count the frequency of three-letter DNA codons across three reading frames (starting at positions 0, 1, and 2).

## Requirements
- **buildCodonMap()** — Count codon occurrences using a HashMap.
- **getMostCommonCodon()** — Find the most frequently occurring codon.
- **printCodonCounts()** — Display codons within a specified frequency range.
- **tester()** — Read a DNA file, analyze all reading frames, and display results.

## Concepts Practiced
- HashMap
- String manipulation
- Loops and indexing
- Constructors and methods
- File handling using FileResource
